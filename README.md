# TrabajosPracticosJava
Desarrolle las siguientes calculadoras matemáticas que tiene: área y perímetro de un círculo, hipotenusa, potencia, raíces cuadradas, logaritmos, interés compuesto,  generador de números aleatorios y simulador de lanzamiento de dados en en lenguaje de programación Java. También hay validaciones con sus respectivos resultados: Validación de contraseña y Validación de número de teléfono. Un comparador de cadena de caracteres sin el método “Equals”, con entrada, procesamiento y salida de datos. Validación utilizando ls clase "String" para validación  de nombre y por otro lado de fecha.
